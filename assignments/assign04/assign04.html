Assignment 4: Webscraping 1 with R (rvest)

Author

Nedret Sen Cavus

Objective

This assignment focuses on scraping, cleaning, and organizing data from Wikipedia using the rvest and tidyverse packages. The goal is to transform unstructured HTML tables into tidy datasets suitable for analysis.

The three datasets targeted are:

  1. Foreign Exchange Reserves
  2. Life Expectancy
  3. Nobel Laureates by Country

A. Setup

I used the rvest package for scraping the HTML data and stringr for text cleaning (splitting strings to remove footnotes).

Code 
library(tidyverse)
library(rvest)
library(stringr)
library(janitor)

3. Nobel Laureates

I scraped the Nobel Laureates table and and cleaned it up.

Code 
url_nobel <- "https://en.wikipedia.org/wiki/List_of_Nobel_laureates_by_country"
wiki_nobel <- read_html(url_nobel)

# Get all tables
nobel_table <- wiki_nobel %>%
  html_nodes(xpath='//table[contains(@class, "wikitable")][1]') %>%
  html_table(fill = TRUE)

# Pick the table with the most rows
nobel_df <- nobel_table[[1]]

names(nobel_df) <- c("Country", "Number of Nobel Prizes")

# Clean Country Name (remove footnotes like [1])
nobel_df$Country <- str_split_fixed(nobel_df$Country, "\\[", n = 2)[, 1]
nobel_df$Country <- trimws(nobel_df$Country)

write.csv(nobel_df, "nobel_clean.csv", row.names = FALSE)

message("Nobel Data Scraped: ", nrow(nobel_df), " rows.")

C. Data Plan for Research

Acquiring web data for research requires a robust and ethical “Data Plan.” If I were to scale this project, I would follow these steps:

  1. Source Verification & Ethics:
    • Check robots.txt (e.g., wikipedia.org/robots.txt) to ensure scraping is permitted.
    • Prioritize official APIs (e.g., World Bank API) over scraping HTML, as HTML structure is brittle and changes frequently.
  2. Data Pipeline:
    • Raw Storage: Always save the raw HTML or JSON responses immediately (writeLines or saveRDS). This allows re-parsing later without re-pinging the server.
    • Cleaning Layer: Use the functions developed above (safe_parse_num, ensure_country_col) to normalize data types immediately.
    • Validation: Implement tests (e.g., “Does every row have a Country?”, “Are reserves > 0?”) to flag scraping errors automatically.
  3. Maintenance:
    • Wikipedia tables often change IDs or column orders. Code should be written to find columns by name (using matches()), not by index position (e.g., df[,5]), to prevent breakage when columns move.

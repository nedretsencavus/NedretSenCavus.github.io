# Overview
This website is created using **RStudio Quarto** and deployed to **GitHub Pages**. Quarto provides a clean, reproducible workflow where site-wide options (title, navbar, theme, and table of contents) are managed in `_quarto.yml`, and content pages are authored in portable `.qmd` files.

# Visual Design
- **Theme:** I use the **cosmo** theme for a professional, readable look with strong defaults for typography and spacing.
- **Consistency:** A single custom stylesheet `styles.css` applies light tweaks while preserving theme consistency.
- **Readability:** The table of contents (TOC) is enabled on longer pages to aid scanning and navigation.

# Navigation & Information Architecture
The navigation bar connects visitors to the site’s core areas:
1. **Home** (`index.qmd`) – brief introduction and purpose.
2. **About** (`about.qmd`) – short bio and contact.
3. **Assignments** (dropdown) – coursework organized by assignment (this page is under **Assignment 1**).
4. **Resume/CV** – a direct link to my updated resume PDF for quick access.

This structure keeps coursework easy to find while also presenting my profile information and credentials.

# Technical Setup
- **Authoring:** `.qmd` files (Quarto Markdown) support standard Markdown and optional code chunks when needed.
- **Configuration:** `_quarto.yml` centralizes the site’s title, navbar, theme, TOC, and custom CSS.
- **Build & Preview:** I use `quarto render` and `quarto preview` locally to test layout and links.
- **Deployment:** Publishing is done to GitHub Pages, which serves the site at `https://<username>.github.io`.

# Rationale & Future Enhancements
The goal is a **clean, professional, and low-maintenance** site. Quarto’s structure keeps content organized, while the cosmo theme ensures a cohesive visual style. Future improvements may include a Projects/Portfolio page, tags for posts, a light/dark mode toggle, and simple analytics.

**Summary:** Built with RStudio Quarto using the **cosmo** theme, this site features clear navigation (Home, About, Assignments, Resume/CV) that connects readers to my content and credentials in a straightforward, professional way.
